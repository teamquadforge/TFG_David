Limitació honesta

Telemetria de xarxa domèstica

Recol·lector Syslog UDP per router/firewall. Port per defecte: 5514/udp. Permet veure DHCP, firewall, DNS, login del router i activitat de dispositius IoT com Smart TV.

Dispositius detectats

Com provar amb el router

  1. Activa syslog remot al router.
  2. Servidor: IP del PC on corre Docker.
  3. Port: 5514 UDP.
  4. Genera trànsit: connecta una TV/mòbil, intenta login al router o activa logs firewall.

Threat intelligence

Si configures ABUSEIPDB_API_KEY, les IPs públiques de la xarxa es contrasten amb AbuseIPDB. Els hashes de descàrregues es poden consultar amb VirusTotal si configures VIRUSTOTAL_API_KEY.
